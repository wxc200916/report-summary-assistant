# 报表自动汇总助手

一个面向行政、运营、销售、财务和小团队的报表整理小工具，用来减少重复汇总周报、月报和业务数据的时间。

## 这个工具解决什么问题
- 每周、每月都要重复整理同类报表
- 多个来源的数据分散，汇总很费时间
- 手工复制粘贴容易出错，格式也不统一
- 做完汇总后还要再整理成固定模板

## 核心功能方向
- 多表数据自动汇总
- 固定格式周报 / 月报生成
- 销售、运营、财务数据汇总整理
- 数据分类、汇总、统计
- 报表模板统一输出

## 适合谁使用
- 行政、运营、销售助理
- 财务、出纳、对账辅助场景
- 小公司、工作室、个体经营者
- 需要定期做汇总报表的小团队

## 常见使用场景
- 每周工作周报整理
- 每月销售数据汇总
- 财务月结报表整理
- 多平台业务数据合并输出
- 固定模板报表自动生成
